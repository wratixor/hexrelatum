# Открытый лор Geno-Dice

`lor/wiki/` — отдельный публичный корпус Hexrelatum. В него попадает только
знание, которое допустимо показывать обычному игроку без раскрытия внутреннего
канона, истинной природы мира или непубличных причин событий.

Все начальные статьи временно находятся в нейтральной точке
`[1, 1, 1, 1, 1, 1]`. Координаты будут назначаться отдельно после согласования
шестнадцати навыков: по два навыка для каждой из восьми троек характеристик, но
с разными точными отношениями внутри тройки.

Сборка и проверка:

```powershell
python tools/build_index.py --corpus lor
python tools/build_index.py --corpus lor --check
```

Локальное чтение после запуска HTTP-сервера из корня репозитория:
`http://127.0.0.1:8765/lor/`.
